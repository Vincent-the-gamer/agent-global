# Agent Global

An opinionated AI Agent initial harness setup.

## Usage

Send the message to your agent:

```
Visit https://github.com/Vincent-the-gamer/agent-global, download the AGENTS.md, ask me for the skills in skill-list.md and let me choose(allow me choose nothing), and where I put these files(global: `~/.agents/skills and ~/.agents/AGENTS.md`, scoped: workspace).
```
